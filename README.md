# 🎮 Квиз: Осмотр слизистых оболочек и ВКН

Интерактивный клинический квиз для ветеринарных специалистов с **голосовой обратной связью** и игровым дизайном в сине-голубых тонах.

![Quiz Preview](public/audio/../logo.svg)

## ✨ Возможности

- 🎨 **Игровой UI в сине-голубых тонах** — анимированный фон с пузырями, конфетти при правильном ответе, плавные переходы
- 🎙️ **Голосовая обратная связь через TTS (z-ai-web-dev-sdk)**:
  - При правильном ответе чередует: «Молодец!» → «Верно!» → «Точно!» (тёплый голос `tongtong`)
  - При ошибке играет случайный вариант: «Ой!» / «Ой-ой!» / «Ой, не-а!» (живой милый голос `chuichui`)
  - Финальное сообщение зависит от результата
- 📊 **Счёт очков в реальном времени**, прогресс-бар, финальный экран с процентом и пересмотром ответов
- ⌨️ **Управление с клавиатуры** — клавиши 1, 2, 3 для выбора варианта
- 📱 **Адаптивный дизайн** (mobile-first)
- ♿ Accessibility: семантическая разметка, ARIA, sr-only для экранных читалок
- 🎬 **Инфраструктура для видео-оверлея** — данные вопросов содержат поле `videoTimestamp`, в компоненте есть `videoUrl` placeholder для будущей интеграции

## 🛠️ Технологии

- **Next.js 16** (App Router, Turbopack)
- **TypeScript 5**
- **Tailwind CSS 4** + **shadcn/ui**
- **Framer Motion** для анимаций
- **z-ai-web-dev-sdk** для TTS

## 🚀 Запуск локально

```bash
# Установить зависимости
bun install

# Запустить dev-сервер
bun run dev
# Открыть http://localhost:3000
```

## ➕ Добавление новых вопросов

Откройте `src/lib/quiz-data.ts` и добавьте новый объект в массив `QUIZ_QUESTIONS`:

```typescript
{
  id: 3,
  topic: 'Тема блока',
  title: 'Вопрос 3',
  question: 'Текст вопроса?',
  options: [
    { letter: 'А', text: 'Вариант', correct: true },
    { letter: 'Б', text: 'Вариант', correct: false },
    { letter: 'В', text: 'Вариант', correct: false },
  ],
  explanation: 'Пояснение после ответа.',
  videoTimestamp: 60, // секунда в видео, когда показывать вопрос
}
```

## 🔊 Регенерация голосовых фраз

Если хотите изменить голоса или добавить новые фразы, отредактируйте `scripts/generate-tts.ts` и запустите:

```bash
bun run scripts/generate-tts.ts
```

Доступные голоса: `tongtong` (тёплый), `chuichui` (милый/смешной), `xiaochen` (профессиональный), `jam` (британский), `kazi` (стандартный), `douji` (естественный), `luodo` (эмоциональный).

## 🎬 Подключение видео (TODO)

Когда у вас появится видеофайл:
1. Поместите его в `public/video/lecture.mp4`
2. В `quiz-app.tsx` установите `videoUrl.current = '/video/lecture.mp4'`
3. Добавьте `<video>` компонент с обработчиком `onTimeUpdate`, который будет переключать фазу на `'question'`, когда `video.currentTime` достигает `videoTimestamp` вопроса
4. После ответа — `video.play()` для продолжения
